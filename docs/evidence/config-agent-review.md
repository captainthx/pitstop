Byte/depth, Unicode, duplicate keys, unselected checks, selection, text and aggregate limits have substantial regression coverage.

The installer verifies staging, authenticates exact trusted manifests and every listed file, rejects extras/symlinks, retains the original until staging completes, rolls back failed publication, and blocks re-entry with retained backup state.
- The portable assets are one source for both presets and installed resources. The skill distinguishes configuration validity, prerequisites and execution; it treats repository instructions as data and avoids inventing checks or deployment scope.
- The evidence separates 14 cases / 23 actual evaluator attempts from four selected runtime toolchains. Failed trials, earlier gate failures, unavailable tooling, and remote/native-platform gaps remain visible. 3. **[P2] Keep syntax-error JSON detection consistent with Cobra's parsed flags.**

Prefer the parsed flag value where available, and make the fallback consume every known value-taking flag and use the same boolean grammar as Cobra. Add syntax-error cases for both newly introduced string flags and supported false spellings.

Check cancellation immediately after destination resolution, before returning its error or reporting a dry-run success, while retaining the established post-publish success ruling. 5. **[P2] Escape untrusted filesystem text in human diagnostics and recovery output.**

Escape control/format characters in human-facing paths/messages and bound displayed recovery text without changing the actual path used by filesystem operations or truncating machine-readable path fields. Cover recovery filenames and repository paths, and preserve useful recovery location information. Review the common human error/result path so the fix is applied consistently rather than only at this one concatenation.
